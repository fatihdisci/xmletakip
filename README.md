# UYAP e-Takip XML Hazırlayıcı

Tarayıcıda, verileri cihaz dışına göndermeden XML hazırlar.

Desteklenen akışlar:

- İlamsız Genel Haciz Yoluyla Takip — Örnek 7
- İlamlı para veya teminat verilmesine ilişkin ilamların icrası — Örnek 4-5

Uygulama, 06.03.2026 tarihli UYAP e-Takip paketindeki `exchange.dtd` ve kod tabloları temel alınarak hazırlanmıştır. UYAP'ın son yükleme kontrolleri ile takip talebinin hukuki içeriği kullanıcı sorumluluğundadır.
